# LinqtoCSV

Third-party LINQtoCSV working copy. CsvContext.Read/Write maps CSV rows onto typed objects using CsvColumn/CsvFileDescription (separator, culture, header row); SampleCode.Program reads products.csv and writes a Netherlands subset. Open `LINQtoCSV.sln`. Original authorship stays with the LINQtoCSV authors; see THIRD_PARTY_NOTICES.md.
